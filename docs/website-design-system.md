# RepPulse website design system

## Direction

Minimal Pulse: a dark sports/tech interface with clear hierarchy, compact information and lime accents. No gradients, glassmorphism or external font dependency. The official Android wordmark is reused from `assets/brand/title_reppulse.png`; it is not redrawn.

## Tokens

- Ink: `#101110`
- Panel: `#202420`
- Lime accent: `#C4F535`
- Text: `#F6F8F2`
- Muted text: `#A9AFA5`
- Divider: `#394039`

## Components

The site uses a responsive header, primary/outline buttons, feature cards, an accessible interval-demo card, evidence gallery, prose pages and a compact footer. Motion is limited to button hover and smooth scrolling, with `prefers-reduced-motion` support.

## Theme concepts

1. **Racing Performance** — the current/default Android direction, focused on high-contrast training controls.
2. **Minimal Pulse** — this website concept: circular lime countdown, phase color coding and compact workout context.
3. **Pure Focus** — provisional future name for an ultra-minimal digital countdown with a linear progress bar.

Only the website concept is represented here. None of these theme concepts is implemented or changed in the Android app.

## Content rules

Only features confirmed in the Android project are described: Tabata/interval workouts, multiple countdowns, stopwatch, optional feedback and Android orientation support. The phone visual is labeled concept/demo; QA gallery captions identify real evidence.
